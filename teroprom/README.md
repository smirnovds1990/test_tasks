## Тестовые задания для вакансии Python-разработчика.
Скачайте репозиторий, создайте виртуальное окружение и установите зависимости:
```bash
git clone https://github.com/smirnovds1990/teroprom.git
cd teroprom
python -m venv venv  # Если не работает, то `python3`
source venv/bin/activate  # для Windows — `source venv/Scripts/activate`
pip install -r requirements.txt
```
___

cd task_1
python main.py
# Результаты сохраняются в файл "task_1/result.xlsx"
